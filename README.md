SOC Phishing Email Investigation

Project Overview

This project demonstrates a beginner-level Security Operations Centre (SOC) investigation into a simulated phishing email.

The objective is to identify phishing indicators, assess potential risks and document findings using a structured security investigation process.

Investigation Scenario

An employee receives a suspicious email claiming that their Microsoft account will be suspended unless they verify their account urgently.

Investigation Objectives

* Identify suspicious sender information.
* Examine the email subject and message content.
* Identify social engineering techniques.
* Assess potential phishing indicators.
* Document findings and recommend security actions.

Tools and Technologies

* GitHub – Project documentation.
* Email header analysis – Planned investigation.
* VirusTotal – Planned URL and file reputation checks.
* Wireshark – Future network investigation practice.

Initial Findings

Indicator	Observation
Urgent language	Yes
Account suspension threat	Yes
Pressure to act quickly	Yes
Suspicious sender domain	Requires further investigation
Malicious link	Not yet established

Initial Assessment

The simulated email contains multiple characteristics commonly associated with phishing attacks.

Further investigation is required before confirming whether the email is malicious.

Status
